# 初任給コンパス 🧭

**就活生・新社会人のための給料&生活シミュレーター**

年収を入れるだけで手取りがわかる「かんたん」から、キャリアシナリオを織り込んだ数年間の家計シミュレーション、社宅や福利厚生まで含めた企業の「実質」比較まで。就職先を選ぶときに気になるお金の疑問に、ブラウザだけで答えます。

## 使い方

`index.html` をブラウザで開くだけです。ビルド・サーバー・外部ライブラリは不要(単一HTMLファイル)。

GitHub Pages で公開する場合は、リポジトリの Settings → Pages でこのブランチを選ぶだけで `index.html` が配信されます。

## 3つのモード

### 1. かんたん
- 年収(額面)を入れるだけで **手取り年収・月々の手取り・賞与の手取り** を概算(スライダーは3,000万円・入力は1億円まで)
- 内訳を「給与明細風」+帯グラフで表示(健康保険・厚生年金・雇用保険・所得税・住民税)
- **1年目は住民税がかからない**ぶん手取りが多いことも表示
- **モデルプラン**: 節約型/バランス型/ゆとり型から選ぶと、手取りに合わせた家賃・食費・貯蓄の配分と「どんな生活になるか」のイメージを自動提示。ワンクリックで「じっくり」タブに読み込み可能
- 年収別の手取り早見表(200万〜2,000万円)つき

### 2. じっくり
入力は**3段階の細かさ**(シンプル/標準/こだわり)から選べます。

- 給与は **月給+賞与ヶ月数** でも **年収(基本給年額+賞与年額)** でも入力OK(コンサルの「ベースサラリー+ボーナス」提示にも対応)
- キャリアの伸ばし方は2方式:
  - **昇給率+昇進イベント**(「4年目に主任で月給+3万円」など)
  - **年収の直接指定**(「3年目に450万、5年目に600万」— 間の年は複利で補間、最終ポイント以降は直前の伸び率が継続)
- **楽観・悲観シナリオ比較**: 昇進時期±N年・金額±N%の幅を指定して、標準/楽観/悲観の3本の手取りカーブとサマリー表を表示
- **1年目は4月入社**モード(給与9ヶ月分・賞与半分・生活費9ヶ月分。2年目の住民税も按分後所得で計算)
- 住まいは実家/賃貸/住宅手当/借り上げ社宅の4方式。賃貸は「金額指定」のほか「**手取りの◯%(上限つき)**」でも指定でき、昇給に合わせて住み替える想定ができます
- 生活費(奨学金返済を含む7項目)は費目ごとに **定額** or **手取り連動(%+上限)** を選択可。「支出の上昇率」で毎年のインフレ・生活水準上昇も反映
- **単発の大きな支出**(海外旅行・引越し・結婚式など)を年指定で追加可能
- 手取り時給(額面時給併記)、最長30年の年次表・チャート、「2年目の壁」警告つき

### 3. 企業くらべ(最大3社)
- 各社とも **月給** でも **年収** でも入力可能。月給300万円・残業100時間・社宅自己負担30万円など上限も拡張済み
- 額面ではなく「**実質的に使えるお金** = 手取り − 住居自己負担 − 通勤自己負担 + 福利厚生の価値」で比較
- **実質時給**(実質可処分 ÷ 残業込み労働時間)と **10年累計** も算出
- 額面と実質で順位が入れかわると教えてくれます

## 計算の前提(概算です)

- **社会保険**: 協会けんぽ(初期値: 東京・令和7年度 9.91%)/厚生年金 18.3%/雇用保険 0.55%。健保・厚年は労使折半の本人負担分。40〜64歳は介護保険 1.59% を自動加算。標準報酬月額の等級は簡略化(月額そのまま・上限あり、賞与上限も考慮)
- **所得税**: 令和7年度税制改正後の給与所得控除(最低65万円)・基礎控除(58万円、低所得は最大95万円 ※令和9年分以降の恒久ルール)+復興特別所得税 2.1%
- **住民税**: 所得割10%+均等割・森林環境税 5,000円、調整控除 2,500円。**前年所得課税のため複数年シミュレーションでは1年目0円**
- 単身・扶養なしを想定。通勤手当は非課税(月15万円まで)だが社会保険料の算定に含む
- 実際の金額は健康保険組合・自治体・企業制度により変わります。意思決定の「目安」としてご利用ください

## 技術メモ

- 依存ゼロの単一 `index.html`(Vanilla JS + 手書きSVGチャート)
- ライト/ダークテーマ対応(OS追従+手動切替)、モバイル対応
- 入力はブラウザの `localStorage` にのみ保存(外部送信なし)
- 税・保険の計算ロジックは `/*ENGINE-START*/ 〜 /*ENGINE-END*/` ブロックに分離してあり、Node.js でそのまま単体テストできます
